# Trainee Performance and Assessment Management System

A Python and PostgreSQL based command-line application for managing trainee profiles, performance, attendance, assignments, and assessment eligibility.

## Objective

The system is designed to manage trainee records and evaluate their performance and assessment eligibility based on defined business rules.

## Features

- Add trainee records
- Search trainees by ID or name
- Update trainee information
- Display trainee records
- Calculate performance ratings
- Evaluate assessment eligibility
- Display reasons for ineligibility
- Generate performance reports
- Store trainee data in PostgreSQL
- Maintain application logs
- Ingest trainee data from CSV files

## Technologies

- Python
- PostgreSQL
- Git
- GitHub
